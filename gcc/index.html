Introduction ¶

介绍 ¶

This manual documents how to use the GNU compilers, as well as their features and incompatibilities, and how to report bugs. It corresponds to the compilers (GCC) version 12.5.0. The internals of the GNU compilers, including how to port them to new targets and some information about how to write front ends for new languages, are documented in a separate manual. See Introduction in GNU Compiler Collection (GCC) Internals.

本手册介绍如何使用 GNU 编译器，以及它们的特性和不兼容性，并介绍如何报告错误。本手册对应于编译器（GCC）12.5.0 版。GNU 编译器的内部原理（包括如何将其移植到新的目标，以及如何为新的语言编写前端的一些信息）记录在另一份手册中。请参阅 介绍（GNU 编译器集合（GCC）内部原理）。
